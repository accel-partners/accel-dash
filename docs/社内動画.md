# 社内動画（accel-dash.com/videos）

MTG議事録・マニュアル・勉強用の動画を Vimeo から出すページ。仕組みはビジネスカレッジの動画（college.accel-dash.com/videos）と同じ。

- Vimeo の「親フォルダ」1 つの中だけを出す。中のフォルダ＝大カテゴリー、その中＝小カテゴリー
- 親フォルダは画面右上の歯車（担当者だけ）で選ぶ。保存先は `video_settings`（supabase/videos.sql）
- 見られる人：担当者（@accel-partners.co.jp）と、ポータルのユーザー管理で「社内動画」にチェックを付けた人。チェックした人はアップロード・フォルダ作成・編集・削除もできる（共通の決まり）
- 親フォルダの外の動画・フォルダは、ID を知っていても API で読めない・触れない（lib/vimeo.ts の folderInLibrary / videoInLibrary）
- アップロードはブラウザ → Vimeo に直接（tus）。サーバーは枠を作るだけなので、長い録画でも Vercel の上限にかからない
- アップロードした動画は「Vimeo 上では非表示・埋め込みは accel-dash.com だけ」にする。Vimeo のプランや権限でできないときは「限定公開（URL を知っている人）」のまま（画面に出る）
- 一覧は 1 分だけサーバーで覚える。画面の更新ボタンで読み直し

## 最初の設定
1. Supabase の SQL エディタで `supabase/videos.sql` を実行（アプリのタイルと設定のテーブル）
2. Vercel（accel-dash）の環境変数に `VIMEO_ACCESS_TOKEN`（ビジネスカレッジと同じトークンでよい。Sensitive で）
   ```bash
   cd ~/projects/accel-dash
   vercel env add VIMEO_ACCESS_TOKEN production --sensitive --scope accelpartners   # 値を貼って Enter
   ```
   必要な権限：Public / Private / Create / Edit / Delete / Upload / Interact / Video Files
3. デプロイ後、accel-dash.com/videos を開き、歯車から親フォルダを選ぶ
4. 社外の人に見せるときは、ポータルのユーザー管理で「社内動画」にチェック
